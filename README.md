# BIEN
Игра от Snotra-Games. BIEN!
Игра была создана для Windows, Android, к сожалению, не подойдет. Но Snotra-Games попытается создать игру и для Android, когда она будет создана она будет добавлена в этот репозиторий.
Приятной игры!

Разница между версиями:
1 версия. Всем знакомая игра с фиолетовым фоном. Там есть всё необходимое, счёчик, мяч, платформа.

Во второй же версии уже можно поменять обычный фиолетовый фон на случайный цвет, нажав на салатовую кнопку в верхнем левом углу.

На днях наша компания добавит третью версию. Там уже нужен код для входа, но есть demoверсия.
